# Saber ERP

نظام إدارة مطاعم متكامل (كاشير، مخزون، موظفين، تقارير، تعدّد مطاعم).

## روابط الاستخدام

- **مطعم عادي (زبون):** `index.html?r=كود_المطعم`
- **لوحة المنصة (المالكة بس):** `index.html?admin=1`

## قبل أول استخدام

1. نفّذي SQL إنشاء الجداول الأساسية بقاعدة بيانات Supabase (`tenants`، وباقي جداول النظام).
2. من لوحة المنصة (`?admin=1`)، أضيفي أول مطعم وحطي له كود ورصيد طلبات.
3. غيّري رمز دخول المنصة (`PLATFORM_ADMIN_PIN` بالكود) لرقم من عندك.

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | النظام كامل (الملف الرئيسي) |
| `manifest.json` + `icon-*.png` | تثبيت النظام كتطبيق على الموبايل/الكمبيوتر |
| `sw.js` | Service Worker — تحديث تلقائي بدون إعادة تحميل يدوي |
| `Saber-ERP-Print-Agent.bat` / `.ps1` | وكيل طباعة محلي لربط الطابعة الحرارية بالشبكة |
| `Saber-ERP-POS.bat` | تشغيل النظام بوضع كشك (كل زبون يحط رابطه الخاص فيه) |
